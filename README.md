# ms-automotivegroup.com

Firmenseite der MS Automotive Group GmbH (statisch, GitHub Pages), Version v3 vom 17.10.2026 (neutral als Dachmarke, ohne Reifen und ohne TyreX-Rot). Gebaut von Claude im CI v4.0, Texte und Freigabe SW/MPO.

- `index.html`: Vorstellung, Kachel je Marke (TyreX), Kontakt
- `impressum.html`, `datenschutz.html`, `404.html`
- `assets/`: Logos, Schrift Barlow (lokal, auf die benötigten Zeichen verkleinert, SIL OFL), `stil.css`
- `CNAME`: eigene Domain für GitHub Pages

Weitere Marke (z. B. DriveX): die auskommentierte Kachel in `index.html` übernehmen, Logo nach `assets/`.
Keine Cookies, keine Analyse, keine externen Dienste. Bei Änderungen daran die Datenschutzerklärung anpassen.
